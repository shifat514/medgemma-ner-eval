How far a 4B open model gets at pulling codable findings out of a clinical note.

What is being measured

MedGemma reads a note and extracts medical findings. It does not produce codes. Downstream, each extracted term goes into the SNOMED lookup, which returns the adjacent ICD code. Asking an LLM for codes directly compounds two hard problems into one and produces too many errors.

Extraction is therefore the ceiling on the whole pipeline: the lookup can never recover a code whose term was never extracted. This benchmark measures where that ceiling sits for MedGemma-4B, zero-shot. There is no baseline to beat. The output is a number, and Ehtesham sets the bar it has to clear.

What counts as a correct extraction

Three columns describe each billed code. Matching any one of them counts.

Evidence textwhat the note says (depression)
Code descriptionICD catalogue wording (Major depressive disorder, single episode, unspecified)
SNOMED termsclinical synonyms for the same concept

That gives a median of 4 accepted phrasings per row, against 1 in the pilot. Recall is reported per row (100) and per distinct code (91).

How a match is decided

Matching is approximate, not exact. Each level contains the one above it, and recall is reported at every level so the cost of each degree of looseness is visible rather than hidden in one threshold.

LevelRuleCatches
L1 exactidentical after normalisingbaseline
L2 containsone is a whole-word subset of the otherback pain ⊂ chronic back pain
L3 similarword overlap + character similaritytypos, word order
L4 embeddingsbiomedical sentence model, cosineHTN → hypertension
L5 LLM judgemodel decides if two phrases mean the samedeferred — see below

L4 is the level that earns its keep. Abbreviations are the largest single source of missed matches and no amount of string similarity reaches them: CHF and congestive heart failure share almost no characters. Only semantic matching closes that gap.

What is reported

Recallheadline. Of the billed codes, how many were found
Precision, F1secondary; false positives are watched, not ignored

Not-in-note ratehallucination: terms the model produced that aren't in the text

Every figure is given at every matching level.

The number that makes recall meaningful

With loose matching and no volume control, a model that lists every phrase in the note scores near 1.00. Recall alone therefore cannot rank two models — a smaller, more verbose one would appear to beat a larger, more disciplined one.

So recall is always quoted with the terms-per-note it was bought with: “0.72 at 20 terms per note”, never a bare 0.72. This is what keeps the benchmark usable when we compare MedGemma against a larger model later.

Prompt change

The pilot prompt asked the model to copy spans verbatim. That was right when the note's own wording was the only target; it is now wrong, because HTN can never string-match Essential (primary) hypertension.

The rewritten prompt asks for two fields per finding: the span as written in the note, and the standard clinical name. Either may match. MedGemma already knows the expansions, and the standard name is also what the SNOMED lookup wants downstream. To hold output length steady, the prompt asks for one entry per distinct finding and no repeats.

Deferred: the LLM judge

Recall rises at every level by construction, so L4 will always look best. The honest question is which level is still counting genuine matches, and the way to settle it is to have a model judge a sample of the pairs each level newly accepted.

It is slow and non-deterministic, so it is not run for now. It stays as the audit step, to be added when a specific level's number is challenged or when the result is close to the acceptance bar.

Reference point

A 50-note pilot on the wider MDACE corpus, scored the strict way (exact matching, evidence text only) returned recall 0.53, against Ehtesham's independently observed ≈0.5. That is the floor this plan is designed to lift: every change above widens what counts as correct without touching the model.

Scope. Extraction only. ICD code prediction is a separate experiment and is not measured here. MedGemma-4B-it · 4-bit · greedy · zero-shot
